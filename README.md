## Read and Process a Text File
## Project Description
This project is developed using Python.
It reads a text file and generates statistics
such as line count, word count, and character count.
## Objective
To understand Python file handling and text processing concepts.
## Technologies Used
- Python 3
- File Handling
- Text Processing
## Features
- Reads a text file.
- Counts the total number of lines.
- Counts the total number of words.
- Counts the total number of characters.
- Handles missing files and other errors.
- Reads files line by line.
## How to Run
1. Install Python 3.
2. Keep all project files in one folder.
3. Open the terminal in that folder.
4. Run the following command:
   python main.py
## Sample Output
Total Lines: 3
Total Words: 13
Total Characters: 81
## Learning Outcomes
- Understanding file handling.
- Using the open() function.
- Learning word and character counting.
- Handling file-related exceptions.
